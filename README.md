# Кликер «Клац»

Онлайн-кликер для телефона. Пользователь попадает на страницу по QR-коду, видит розовый экран загрузки с танцем розового дед-бэтмена и фламинго, затем нажимает большую круглую кнопку **КЛАЦ**.

## Как запустить проект в Kodik

1. Открыть файл workspace в Kodik:  
   `C:\Users\Иоанн\Desktop\Кликер\pink-clicker.code-workspace`
2. Запустить локальный сервер в папке `Кликер`:  
   `node server.js`
3. Открыть `http://127.0.0.1:8080`.
4. Для проверки на телефоне — опубликовать на HTTPS-хостинге и перейти по ссылке.

## Сценарий

1. Сканирование QR-кода → переход на страницу.
2. Розовый фон.
3. Экран загрузки с шестисекундным танцем из видео:
   - розовый дед-бэтмен и фламинго танцуют на розовом фоне;
   - музыка включается кнопкой, ручного пропуска заставки нет;
   - при ошибке/зависании есть защитный переход через 10 секунд.
4. Появляется большая круглая кнопка **КЛАЦ**.
5. Нажатие:
   - счётчик увеличивается на 1;
   - появляется облако с случайной репликой;
   - облако поднимается вверх и испаряется.
6. Каждые 100 нажатий:
   - окно «Поздравляем! Получен подарок»;
   - подарок каждый раз разный: обои на телефон, стикерпак и т. д.

## Пошаговый план разработки и запуска

### Шаг 0. Запуск и проверка стартовой версии
1. Открыть `pink-clicker.code-workspace` в Kodik.
2. В папке `Кликер` запустить локальный сервер: `node server.js`.
3. Открыть `http://127.0.0.1:8080`.
4. Проверить сценарий: розовый экран → танец персонажей из видео → после ролика появляется круглая кнопка **КЛАЦ**; каждый клик увеличивает счётчик на кнопке. Кнопка «Включить музыку» работает во время заставки.

### Шаг 1. Предыдущий вариант загрузчика (история разработки)

Этот SVG-загрузчик заменён танцем из MP4 с музыкой; актуальный вариант описан в конце README. Вырезки и инструменты ниже сохранены.
- [x] Вырезать полнофигурных персонажей из нижней правой панели комикса в прозрачные PNG.
- [x] Разместить их в SVG внутри `#loader`, выделив голову, руки/крыло и ноги масками.
- [x] Анимировать части тела: покачивание, движения рук, кивки и попеременные шаги. GIF используется только как референс, а не как изображение на странице.
- [x] Начинать танец после загрузки ресурсов; переключаться после трёх `animationiteration`, с резервным таймером.
- [x] Возвращать фигуры в исходную позу перед открытием кнопки; при `prefers-reduced-motion` пропускать танец.

Вырезки можно воспроизвести на Windows: `powershell -NoProfile -File tools/extract-characters.ps1`.
Это перекладная анимация частей исходного рисунка, а не покадровая перерисовка поз из GIF.
Проверки без дополнительных зависимостей: `node --test tests/app.test.js`.

## Важно

- Используй только свои или лицензионно свободные изображения.

## Текущий экран загрузки: танец из видео с музыкой

- Каждое нажатие «КЛАЦ» воспроизводит предоставленный «Клик.wav» (`assets/click.wav`); каждое сотое (100, 200, 300, 400 и далее) — «Последнее нажатие.wav» (`assets/milestone-click.wav`) вместо обычного клика. Быстрые клики перезапускают звук без наложения. Звуки включаются только по нажатию и останавливаются при скрытии страницы; ошибки звука не мешают счётчику.
- На 300-м нажатии появляются конфетти и окно «Ты заслужил открытку!» с текстом «Порадуй близких открыткой от любимых персонажей by KsVs.». Ссылка «Получить открытку» открывает изображение открытки (`assets/postcard.png`) в новой вкладке.
- Облака содержат только текст реплики, без имени героя. Точка появления привязана к середине головы в исходном кадре: Бэтмен (156, 188), фламинго (348, 213); при масштабировании сцены привязка сохраняется.
- На каждом 9-м клике возле говорящего героя появляется облако с репликой, поднимается и растворяется. В `quotes.js` сохранены все 40 одиночных фраз и 6 перепалок; перепалки выпадают с вероятностью 12%, вторая реплика появляется на 0,65 с позже. В каждой группе фразы перемешиваются без повторов до исчерпания. Старые облака заменяются новой репликой/парой и удаляются через 6,2 с; окна подарков очищают их. При уменьшении движения реплики показываются неподвижно и затем исчезают.
- На 200-м нажатии снова появляются конфетти и поздравление «Ты молодец!» с текстом «Держи еще один танец от твоих любимых персонажей by KsVS.». Кнопка «Получить видео» открывает `assets/reward-dance.mp4` в новой вкладке: это неизменённый предоставленный файл `veo-3-1.mp4`. Видео не загружается до перехода по ссылке; заставка использует прежний ролик.
- На 100-м нажатии открывается модальное поздравление и сверху сыплется конфетти. Закрытие — крестиком или Escape, фокус возвращается на «КЛАЦ». Частицы удаляются через 7 секунд или при закрытии; уменьшение движения отключает конфетти. Кнопка «Получить стикерпак» открывает https://t.me/addstickers/KsVsebudethorosho в новой вкладке (`target="_blank"`, `rel="noopener noreferrer"`), не закрывая приложение.
- На розовом фоне — затемнённая декоративная эмблема `assets/emblem.svg`, векторная интерпретация присланного образца (не исходная растровая картинка). Подложка не перехватывает нажатия и остаётся позади сцены.
- После заставки каждое нажатие «КЛАЦ» запускает общий прыжок персонажей (420 мс). Кнопка и надпись не прыгают. Быстрое повторное нажатие перезапускает прыжок; при `prefers-reduced-motion: reduce` персонажи остаются неподвижными, счётчик работает.
- Одновременно с появлением кнопки сверху медленно спускается надпись «Клацай 100 раз и получи подарок» — жёлтые объёмные буквы с чёрной обводкой. Она останавливается над розовым персонажем; при уменьшении движения в настройках системы появляется сразу.

- `assets/loader-dance.mp4` — предоставленный ролик (448×672, 6 секунд, около 2,8 МБ), включая исходную музыку. Старые GIF и вырезки сохранены, но загрузчик их не использует.
- `matte.js` отделяет розовых персонажей от лунного фона по цветам и связности пикселей. Canvas рисует их на розовом фоне сайта; это программная цветовая маска, не нейросетевое удаление фона. На тонких контурах возможны небольшие артефакты.
- Танец автоматически начинается **без звука**. Кнопка **«Включить музыку»** разрешает звук по жесту пользователя, как требуют мобильные браузеры. Повторное нажатие отключает звук. Используется один видеоэлемент, поэтому музыка и движения не расходятся.
- Во время танца весь кадр вписывается в экран с запасом: минимум 24 px по бокам, 28 px сверху и 116 px снизу под управление. Финальная сцена не изменена. Части, уже обрезанные границами исходного видео, этим не восстанавливаются; края мягко растушёвываются (`edgeFeather`). Подсказки про музыку на экране нет.
- После одного ролика герои застывают в позе с 0-й секунды и остаются на экране. Справа медленно (2,6 с) выплывает кнопка **КЛАЦ** и встаёт в центр экрана; герои остаются неподвижными. Пока страница действительно загружается, ролик повторяется. Кнопки ручного пропуска нет. Защитный таймер (10 секунд), ошибка видео или недоступность canvas не дают заставке заблокировать сайт.
- При выходе из заставки звук и декодирование прекращаются. В скрытой вкладке воспроизведение приостанавливается. При `prefers-reduced-motion: reduce` ролик не загружается: сразу показывается финальная сцена без анимации.
- `assets/loader-dance.poster.png` — прозрачный статичный кадр до начала воспроизведения. Пересоздать в Windows (Node + штатный WPF, без установки зависимостей):
  `powershell -NoProfile -STA -ExecutionPolicy Bypass -File tools/create-loader-poster.ps1` (по умолчанию кадр 0 с)
- `assets/pose-body.png`, `pose-arm.png`, `pose-neck.png` — финальная поза из того же кадра 0 с, разрезанная на слои: поднятая рука и шея фламинго лежат поверх кнопки, ничего не двигается. После смены постера пересоздать: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/create-pose-layers.ps1`.
  Политика выполнения меняется только для этого процесса.
- `server.js` поддерживает `video/mp4`, `HEAD` и byte ranges (включая Safari). Запуск: `node server.js`, адрес: http://127.0.0.1:8080. Для другого порта в PowerShell: `$env:PORT=8081; node server.js`.
- Все проверки: `node --test`. Проверить на телефоне отдельно: звук после касания, завершение танца, поворот экрана и возврат из фоновой вкладки.
- Для ручной проверки контуров и управления: `/tests/loader-preview.html`. Эта QA-страница загружает настоящую разметку приложения, но повторяет ролик и увеличивает таймер до 120 секунд. Обычный сайт эти настройки не использует.
